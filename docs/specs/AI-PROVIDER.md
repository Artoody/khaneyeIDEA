# مشخصات: لایه‌ی هوش مصنوعی و اتصال به Fallback

## اصل
همه‌ی قابلیت‌های هوش مصنوعی پشت یک رابط واحد (`packages/ai`) هستند. هر قابلیت **بدون AI هم کار می‌کند** (مثلاً معلم گزارش را تایپ می‌کند، ادمین متن اطلاعیه را خودش می‌نویسد) و هر خروجی AI قبل از ارسال **تأیید انسان** دارد.

## رابط
```ts
interface AiProvider {
  generate(req: { system?: string; prompt: string; json?: boolean; maxTokens?: number }): Promise<{ text: string }>;
  transcribe?(audio: Buffer, lang: "fa" | "en"): Promise<{ text: string }>;
}
```
پیکربندی از طریق متغیرهای محیطی و قابل تعویض بدون تغییر کد:
- `AI_PROVIDER=gemini-compatible | openai-compatible | none`
- `AI_BASE_URL`، `AI_API_KEY`، `AI_MODEL`، `AI_TIMEOUT_MS`

## آداپتر «gemini-compatible» (برای پروکسی Fallback)
پروکسی `Artoody/fallback` همان API جمینای را با چرخش خودکار بین چند کلید ارائه می‌دهد:
- درخواست: `POST {AI_BASE_URL}/v1beta/models/{AI_MODEL}:generateContent`
- هدر: `x-goog-api-key: {AI_API_KEY}` (کلید پروکسی از پنل `/admin` پروکسی، **نه** کلید گوگل)
- بدنه و پاسخ: فرمت استاندارد Gemini (`contents[].parts[].text`)
- سلامت: `GET {AI_BASE_URL}/`
- خطاها: `401` کلید پروکسی اشتباه، `502` همه‌ی کلیدهای پشت پروکسی خطا دادند. در هر دو حالت قابلیت به مسیر بدون AI برمی‌گردد و ادمین اعلان می‌گیرد.

## آداپتر «openai-compatible»
برای مدل متن‌باز روی سرور خودمان (مثلاً با vLLM یا Ollama) یا هر سرویس سازگار.

## قواعد داده
- به مدل **اسم کامل، شماره، آدرس یا عکس بچه‌ها** فرستاده نمی‌شود. قبل از ارسال، اسم‌ها با برچسب جایگزین می‌شوند (`دانش‌آموز ۱`) و بعد از پاسخ برگردانده می‌شوند.
- لاگ درخواست‌های AI فقط متن بدون اطلاعات شخصی را نگه می‌دارد.
- محدودیت نرخ و سقف هزینه‌ی روزانه در خود پلتفرم.

## ریسک‌ها (تصمیم با مالک پروژه)
- **شرایط استفاده و دسترسی منطقه‌ای گوگل:** API جمینای برای همه‌ی کشورها ارائه نمی‌شود و شرایط گوگل محدودیت‌هایی درباره‌ی منطقه‌ی استفاده و دور زدن سقف‌های مصرف دارد. اگر کلیدها مسدود شوند، قابلیت‌های AI از کار می‌افتند. این ریسک باید آگاهانه پذیرفته شود.
- **حریم خصوصی:** داده از سرور ایران به پروکسی روی Railway و بعد به گوگل می‌رود. قواعد بالا (حذف اطلاعات شناسایی) الزامی است.
- **وابستگی به اینترنت بین‌الملل:** در قطعی، مسیر بدون AI فعال می‌شود.
- **پیشنهاد بلندمدت:** مدل متن‌باز روی سرور خودمان به‌عنوان مسیر اصلی یا پشتیبان، از طریق آداپتر `openai-compatible`.
